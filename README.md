# 📚 Awesome Speculative Decoding

> Companion Method Profiles for a systems co-design survey of speculative decoding.

[![Awesome](https://img.shields.io/badge/Awesome-0066CC?style=for-the-badge&logo=awesome-lists&logoColor=white)](https://github.com/sindresorhus/awesome)
![Method Profiles](https://img.shields.io/badge/Method%20Profiles-312%20works-2563eb?style=for-the-badge)
[![Survey Paper](https://img.shields.io/badge/Survey-Paper-B31B1B?style=for-the-badge)](https://www.preprints.org/manuscript/202608.0746)
[![Method Profiles Explorer](https://img.shields.io/badge/Method%20Profiles%20Explorer-Live-0F766E?style=for-the-badge)](https://lifeissosolong.github.io/awesome-speculative-decoding/)

Our survey organizes speculative decoding from a **systems co-design perspective** across four connected aspects: **Draft Source**, **Draft Geometry**, **Verification Fidelity**, and **Runtime Execution**. This companion repository provides Method Profiles for all 312 included works, including category assignments, paper and code links, a complete chronological table, and an interactive explorer for filtering, comparing, sharing, and exporting results.

> **Help us keep this resource accurate and up to date.** If you spot an incorrect taxonomy assignment or know of a relevant new work that should be included, please [open an issue](https://github.com/LifeIsSoSolong/awesome-speculative-decoding/issues/new). When possible, include the paper link and a brief explanation of the suggested correction or addition.

## 📦 Fixed snapshot and downloads

- [**Download the 19 September 2026 snapshot (ZIP)**](https://github.com/LifeIsSoSolong/awesome-speculative-decoding/releases/download/method-profiles-2026-09-19/Supplementary_Material.zip) · [Release and checksum](https://github.com/LifeIsSoSolong/awesome-speculative-decoding/releases/tag/method-profiles-2026-09-19)
- [Current explorer data (CSV)](data/coding_matrix.csv)

The ZIP preserves the complete submitted supplementary package. `method_profiles_snapshot/` contains **312 profiles**, classification evidence, category definitions, the matching manuscript, and a standalone script for reproducing the counts. `supplement_source/` contains the readable supplement and its LaTeX source. The package records **1,459 assignments** (1,057 core and 402 inherited) and **83 unassigned work–axis combinations**.

The original corpus was frozen on **20 July 2026**. The **19 September 2026** snapshot incorporates six restored works, two additions, and documented corrections; its date is not a new literature-search cutoff. The current explorer matches this snapshot. Future website updates will be recorded in Git; this versioned download will remain unchanged. For reproducibility, identify the snapshot date and checksum.

After extracting the ZIP, run `python3 reproduce_counts.py --check` from `method_profiles_snapshot/` (Python 3.10 or later). The script checks all seven generated result tables. Category-specific source locators are included where available; empty evidence fields do not imply a separately documented primary-source locator for every assignment.
